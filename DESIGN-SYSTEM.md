# Зелёное Царство — дизайн-система

Источник: Figma «ЗЦ-сайт» (копия `Rok3HsEgsYBGPicyIuZZZ6`). Новые страницы собираем только из этих правил.

## Файлы

| Файл | Что внутри |
|---|---|
| `css/tokens.css` | цвета, градиенты, шрифты, поля, высоты шапки |
| `css/base.css` | сброс, контейнер `.wrap`, видимость по брейкпоинтам, типографика, display-заголовки `.ttl` |
| `css/components.css` | шапка, меню-каталог, подвал, кнопки, карточка товара, сетка, крошки, обложка, тулбар, формат, аккордеон, количество |
| `css/pages.css` | раскладки 6 готовых страниц |
| `js/layout.js` | шапка, меню и подвал — **одно место правки для всех страниц** |
| `js/main.js` | формат и цена, галерея, количество и суммы в корзине |

Каркас страницы — любой готовый `.html`: плейсхолдеры `data-zc="header|menu|footer"` и 2 скрипта в конце.

## Отправка форм → Тильда (почта / Telegram / CRM)
Все формы отправляют данные только через `ZC.send(вид, данные)` в `js/layout.js`. Локально — имитация (данные в консоли).
При переносе на Тильду:
1. На страницу корзины добавить блок с формой Тильды (любой стандартный блок формы), подключить приёмщик «Почта» (и при желании Telegram/CRM). Добавить в форму **скрытые поля** с именами: `order_id, items, total, receive, address, name, phone, channel, comment, consent`. Обязательность у полей Тильды снять.
2. То же на странице торта, поля: `date, weight, filling, inscription, wishes, name, phone, channel, consent`.
3. Скрыть эти блоки (CSS `#recXXXXXXXX { display: none; }` в блоке HTML-кода).
4. В `js/layout.js` вписать id блоков: `var TILDA_FORMS = { order: '#recXXXXXXXX', cake: '#recYYYYYYYY' };`
5. Проверить на опубликованной странице: отправить тестовый заказ, письмо должно прийти, заявка — появиться в «Заявках» Тильды. Если ответ Тильды не пришёл за 10 с, сайт покажет ошибку с телефоном.

## Адаптив между макетными ширинами (12.11)
Макет нарисован на 1440 / 768 / 390, но сайт должен держаться на любой ширине 320–1920.
- Заголовки-SVG `.ttl`: масштаб `--s` как в макете, но картинка ужимается по ширине бокса (`container-type: inline-size` + `min()` в `base.css`), если глифы не помещаются.
- Фиксированные ширины из макета задавать через `max-width` (или `min(Npx, 100%)`), колонки сетки — `minmax(0, 1fr)`.
- Текст с `white-space: pre` из макета — только где ширина гарантирована; иначе `pre-line` / `pre-wrap`.
- 640–767: блоки «фото + текст» (`.media`) — в одну колонку. Шапка < 375 — уменьшенный логотип.
- Проверка: скрипт-аудит (iframe 320…1920 по всем страницам, ищет выход за `.wrap` и горизонтальную прокрутку) — прогонять после правок вёрстки.
- Кэш: у ссылок на css/js стоит `?v=ММДДЧЧММ`. При каждой публикации правок вёрстки менять версию во всех *.html, иначе телефоны показывают старые стили.
